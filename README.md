# PTX Inspector

**A Lightweight C++17 Static Analyzer for NVIDIA PTX Assembly**

PTX Inspector is a command-line tool that analyzes PTX (Parallel Thread Execution) assembly files and provides a summary of instruction types, register declarations, and branch targets.

The project demonstrates basic compiler-related concepts, text parsing, static analysis, and automated testing using C++17.

## Features

- **Instruction Counting:** Counts the total number of PTX instructions.
- **Instruction Classification:** Identifies common arithmetic, comparison, logical, conversion, memory load, memory store, and branch instructions.
- **Opcode Summary:** Displays the frequency of individual instruction opcodes.
- **Register Analysis:** Counts registers declared using common `.reg` declarations.
- **Branch Validation:** Checks whether direct branch instructions refer to existing labels.
- **Error Reporting:** Reports missing branch targets with line numbers.
- **Automated Testing:** Includes sample PTX files and tests for basic functionality.

## Requirements

- A C++17-compatible compiler, such as GCC
- Python 3 to run the automated tests

**Note:** An NVIDIA GPU and CUDA Toolkit are not required to run this static analysis tool.

## Build and Run

### Windows (PowerShell)

Compile the program:

```powershell
g++ -std=c++17 -Wall -Wextra main.cpp -o ptx_inspector.exe
```

Analyze the sample PTX file:

```powershell
.\ptx_inspector.exe .\samples\sample.ptx
```

Check branch validation using an intentionally invalid example:

```powershell
.\ptx_inspector.exe .\samples\bad_branch.ptx
```

### Linux

```bash
g++ -std=c++17 -Wall -Wextra main.cpp -o ptx_inspector
./ptx_inspector samples/sample.ptx
```

Run the included test suite with Python:

```bash

```

The tests compile the program and check instruction counts, successful branch validation, and detection of missing branch targets.

## How It Works

1. Reads the PTX file line by line.
2. Removes comments and ignores directives that are not instructions.
3. Identifies labels and counts register declarations.
4. Extracts instruction opcodes and updates the relevant counters.
5. Records direct branch targets and compares them with the labels found in the file.
6. Displays the analysis results and reports validation errors when a target is missing.

## Limitations

This project is an educational static analyzer, not a complete PTX parser or validator. It supports a subset of common PTX syntax and assumes most instructions are written one per line.

It does not perform complete PTX semantic validation, operand type checking, indirect branch analysis, or GPU execution. The supplied PTX files are illustrative test fixtures and have not been established as compiler-generated executable kernels.
